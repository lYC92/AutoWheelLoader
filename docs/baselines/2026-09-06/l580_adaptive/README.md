# L580 与自适应前处理：三次名义行驶评测

每轮独立启动 Gazebo，执行同一组举升收斗、倒车、制动、前进、停车动作。
三个 `run*/metrics.json` 记录实际配置与展开模型哈希，`trajectory.csv` 保留逐帧误差，
`filter.log` 保留过滤器日志，`status.json` 记录评测完成状态。`summary.json` 是指标汇总。

配置见本目录 `kiss_icp.yaml`。模型使用修复 L580 外观，雷达在 rear_frame 的 z=2.85 m，
效应仍是种子 7、10% 丢点和旋转扫描畸变。过滤器从正式模型读取 15 个可见几何包围盒，
使用扫描时刻 TF、自适应地面识别。初始化关节广播之前有少量 TF 缺失丢帧，正式行驶期间日志无持续缺失。

此前另有两次未产生有效评测的尝试：一次共用临时 URDF 被另一个启动覆盖，导致缺失真值；
一次遭 WSL 重启中断。它们未被计为精度样本。启动器随后隔离了每次运行的模型文件，
并在 Windows 自动修复 WSLg 前检查是否存在活动仿真。

这是同一场景、同一种子下的重复运行；不是多工况统计结论。旧版模型和传感器高度也不同，
不能将 RMSE 差异解释为单独开启某项过滤的提升。尚未接入 IMU 融合或闭环地图，
动态料堆、斜坡和铰接转向行驶的精度仍待验证。
