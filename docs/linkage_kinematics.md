# 工作装置降阶运动学

## 当前边界

当前模型是 `nominal` 软件集成模型，不是特定装载机的标定模型。它用于固定坐标约定、查表
格式、雅可比接口和测试方法；只有用厂家 CAD 铰点、油缸端点和实测行程替换参数并通过全
工作区对照后，才能将状态改为 `validated`。

参数源为
`ros_ws/src/loader_description/config/nominal_linkage.yaml`，表格由
`tools/kinematics/generate_linkage_table.py` 生成。

## 坐标与广义坐标

- 参考系：`front_frame`
- 平面：`x-z`，`x` 向前，`z` 向上
- 关节轴：`[0, -1, 0]`
- `q_lift > 0`：举升臂向上
- `q_tilt > 0`：铲斗后卷

采用两个独立广义坐标 `q_lift` 和 `q_tilt`。令二维旋转矩阵为 `R(q)`，举升枢轴为 `P`，
举升臂到铲斗枢轴的向量为 `a`，铲斗枢轴到斗齿参考点的向量为 `t`，则：

```text
bucket_pivot = P + R(q_lift) a
bucket_pitch = q_lift + q_tilt
bucket_tip   = bucket_pivot + R(bucket_pitch) t
```

每根油缸长度由两安装点的欧氏距离计算。脚本同时输出长度对广义坐标的解析偏导，以及
斗齿位置雅可比。油缸力转换到广义力时使用虚功关系：

```text
tau_i = cylinder_count * cylinder_force * d(length) / d(q_i)
```

力和行程正方向必须在液压模型接入时统一；不得通过直接设置关节位置绕过该映射。

## 当前自检结果

- 查表范围：举升 `[-0.2, 1.1] rad`，翻斗 `[-1.2, 0.8] rad`
- 步长：两轴均为 `0.05 rad`
- 表格行数：1107
- 解析雅可比与中心有限差分最大误差：`7.85e-11`
- 全采样工作区最小绝对有效力臂：`0.070290 m/rad`
- URDF 中两个关节的轴向和上下限与参数文件一致
- 修改关节轴向后，Xacro/URDF 解析和 Gazebo 6 秒落地稳定测试均通过

以上结果只证明数学实现自洽，不证明几何与目标实车一致。

## 升级为 validated 所需输入

1. 举升臂、摇臂、连杆、铲斗和两类油缸的全部 CAD 铰点坐标。
2. 油缸收缩/伸出端的实测长度及机械限位。
3. 斗刃和斗齿点集，以及铲斗容量基准。
4. 至少 10 组覆盖全工作区的 CAD 正解或实车姿态—行程测量点。
5. 连杆间隙、弹性和载荷变形数据；第一版可记录但不一定建模。

对照验收应分别限制油缸长度误差、铲斗角误差和斗齿位置误差，并保存输入数据版本与
生成表的哈希。
